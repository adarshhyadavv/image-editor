Image Editor

A browser-based Image Editor built using HTML, CSS, and JavaScript. It allows users to upload images, adjust different visual filters, apply predefined presets, and download the edited image.

Features

* Upload images from your device.
* Adjust brightness, contrast, saturation, and hue rotation.
* Apply blur, grayscale, sepia, opacity, and invert effects.
* Use predefined filter presets, including Drama, Vintage, Cinematic, Warm, Cool, and Black & White.
* Reset all filters to their default values.
* Preview image edits instantly.
* Download the edited image as a PNG file.
* Responsive and easy-to-use interface.

Technologies Used

* HTML5
* CSS3
* JavaScript
* HTML Canvas API
* Remix Icon

How It Works

1. Select an image from your device.
2. Adjust the filter sliders or choose a preset.
3. Preview the changes on the canvas.
4. Reset the filters if needed.
5. Download the edited image as a PNG file.
